# دوجة ونورهان
موقع ويب بنقاط نيون وقلوب صغيرة متحركة، مع روابط إنستغرام وGoogle Play قابلة للتعديل.

قبل النشر، افتح `public/index.html` واستبدل رابط Instagram العام برابط حساب نورهان الحقيقي، واستبدل رابط Google Play برابط صفحة المطوّر/التطبيق الصحيح. الروابط الحالية عامة وليست روابط شخصية.

للتشغيل: `npm start` (Node.js 18+). على Render: Build `npm install` وStart `npm start`.
